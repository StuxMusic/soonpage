# Coming Soon Page

A clean and simple coming soon page for Stux.Music.

## Overview

This repository contains a lightweight HTML page designed to let users know Stux.Music is on its way. It's perfect for building anticipation ahead of launch.

## Features

- 📄 Simple, clean HTML structure
- ⚡ Lightweight and fast-loading
- 🎨 Ready to customize
- 📱 Responsive design
- 🚀 Deployed at [soonpage.stux.music](https://soonpage.stux.music)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/StuxMusic/soonpage.git
   ```

2. Open `index.html` in your browser or deploy to your hosting provider

## Customization

Edit the HTML files to:
- Update the coming soon message
- Add your branding and logo
- Customize colors and styling
- Include email signup or social links

## Deployment

This project uses GitHub Pages and can be automatically deployed to your desired domain.

The live version is deployed at [soonpage.stux.music](https://soonpage.stux.music).
